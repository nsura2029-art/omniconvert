# Design Mockups DOX

## Purpose
- Owns standalone HTML design explorations used as visual references before production UI changes.

## Ownership
- `index.html` links to the available mockup directions.
- Individual mockup HTML files are static, self-contained references.

## Local Contracts
- Mockups are not production React routes.
- Keep files standalone with inline CSS unless the user asks to integrate them into the app.
- Visual directions should preserve the light, modern SaaS aesthetic and avoid dark-first palette drift.

## Work Guidance
- Use mockups to compare visual systems before changing production components.
- Do not treat mockup layout or text as canonical app behavior.

## Verification
- Open through local Vite, for example `/design-mockups/index.html`, because direct `file://` may be blocked in the in-app browser.
